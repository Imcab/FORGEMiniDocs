    Optimizer

    Optimizer es el gestor de recursos de sistema "Ultimate" de ForgeMini.

    El roboRIO tiene recursos limitados (CPU, RAM y Disco). Esta clase actúa como un "conserje" automático que trabaja en segundo plano para:

    1. Prevenir Lag Spikes gestionando la memoria RAM.
    2. Detectar Loop Overruns (código lento).
    3. Mantener el disco limpio borrando logs antiguos.
    4. Ahorrar ancho de banda desactivando telemetría innecesaria.

    Implementación

    La implementación requiere medir el tiempo de ejecución real de tu robot. Modifica tu archivo Robot.java de la siguiente manera:

    package frc.robot;

import edu.wpi.first.wpilibj.TimedRobot;
import edu.wpi.first.wpilibj.Timer; // Importante
import com.stzteam.forgemini.Optimizer; 

public class Robot extends TimedRobot {

    public Robot() {
        // 1. Inicializa limpieza de disco y optimización de red
        Optimizer.init();
    }

    @Override
    public void robotPeriodic() {
        // 2. Inicia el cronómetro
        double startTime = Timer.getFPGATimestamp();

        // 3. Ejecuta tu Scheduler (Comandos)
        CommandScheduler.getInstance().run();

        // 4. Calcula el tiempo real de ejecución
        double executionTime = Timer.getFPGATimestamp() - startTime;

        // 5. Alimenta al Optimizer con el tiempo real
        Optimizer.update(executionTime);
    }
}

    Importante

    No pases kDefaultPeriod (0.02) al método update(). Si haces eso, el sistema pensará que el robot siempre tarda 20ms y nunca detectará el lag real. Debes calcular la diferencia de tiempo como se muestra arriba.

    Funciones Automáticas

    1. Gestión de Memoria RAM (Smart GC)

    Java utiliza un "Garbage Collector" (GC) para liberar RAM. Si el GC se ejecuta a mitad de un partido, causa un pequeño congelamiento ("stop-the-world").

    • Lógica: Si la RAM usada supera el 65% y el robot está DESHABILITADO.
    • Acción: Optimizer fuerza una limpieza de memoria preventiva mientras el robot está quieto.
    • Beneficio: Entras al partido (Teleop/Auto) con la memoria limpia, reduciendo drásticamente la probabilidad de lag durante la competencia.

    2. Monitoreo de Loop (Anti-Lag)

    El código del robot debe ejecutarse cada 20ms (50Hz). Si tu código tarda más (ej. 25ms), el robot se sentirá "lento" o con "jitter".

    • Detección: Si executionTime > 0.02s.
    • Acción: Incrementa el contador Sys/LoopOverruns en NetworkTables.
    • Uso: Si ves que este número sube durante un match, significa que tienes código ineficiente que debes optimizar.

    3. Limpieza de Logs (Higiene de Disco)

    Los archivos de log pueden llenar el disco del roboRIO, causando fallos críticos en el arranque.

    • Archivos soportados: .wpilog (WPILib DataLog) y .hres (Phoenix 6 Flight Recorder).
    • Límite: Mantiene solo los últimos 10 archivos (configurable).
    • Rendimiento: Corre en un hilo secundario (Thread) para no afectar el tiempo de encendido.

    4. Optimización de Red

    Desactiva automáticamente el LiveWindow de WPILib. Esto libera CPU y reduce el tráfico de red, lo cual es vital para mantener una conexión estable con la FMS y mejorar el rendimiento de las cámaras.

    Configuración Avanzada

    Si necesitas cambiar los valores por defecto, puedes usar los setters estáticos en Robot():

    Método Descripción Valor Default
    Optimizer.setLogDir(String) Cambia la carpeta donde se buscan los logs. /home/lvuser/logs
    Optimizer.setMaxLogs(int) Cambia cuántos archivos de log antiguos guardar. 10
    Optimizer.setLoopOverrunThreshold(double) Cambia el umbral para considerar un ciclo como "lento". 0.02 (20ms)

    Telemetría (Dashboard)

    Optimizer publica automáticamente las siguientes métricas en NetworkTables (tabla Optimizer) para que las veas en Glass o Shuffleboard:

    Key Descripción Estado Ideal
    Sys/LoopTime_ms Tiempo real que tarda tu código en ejecutarse. < 15ms
    Sys/LoopOverruns Contador de veces que el código tardó más de 20ms. 0 (o muy bajo)
    Sys/RAM_Usage_% Porcentaje de memoria RAM utilizada. < 70%
    Sys/RAM_Free_MB Megabytes de RAM libres. > 15 MB
