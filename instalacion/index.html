    Instalación en Java

    Instalación Online

    Este es el método estándar de WPILib. Si tu computadora tiene acceso a internet, sigue estos pasos:

    1. Abre tu proyecto de robot en VS Code.
    2. Haz clic en el icono de WPILib (la 'W' en la esquina superior derecha) o presiona Ctrl+Shift+P.
    3. Escribe y selecciona Manage Vendor Libraries.
    4. Selecciona la opción Install new library (online).
    5. Copia y pega la siguiente URL de instalación en el cuadro de texto y presiona Enter:
    https://Imcab.github.io/FORGEmini/ForgeMini.json

    Success

    VS Code descargará automáticamente los archivos y verás un mensaje de Build Successful siempre y cuando el código del robot no tenga errores.
